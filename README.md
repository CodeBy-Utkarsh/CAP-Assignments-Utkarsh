# CAP-Assignments-Utkarsh

A collection of SAP CAP (Cloud Application Programming Model), Node.js, and SAP Fiori Elements projects, built to demonstrate full-stack enterprise application development — from data modeling and OData services to Fiori-based UIs.

## 🛠️ Tech Stack

- **Backend:** SAP CAP (Node.js), CDS (Core Data Services)
- **Frontend:** SAP Fiori Elements
- **Database:** SQLite (dev), HANA (cloud-ready)
- **Languages:** JavaScript, CDS, HTML

## 📂 Projects

### EPM-Model
Enterprise Procurement Model demo showcasing standard SAP CAP sample data and service exposure via OData.
**Tech:** CAP, CDS, Node.js

### Event-Management
A system to manage events, attendees, and schedules with CRUD operations exposed through OData services.
**Tech:** CAP, CDS, Fiori Elements

### Fleet_Sytem
Fleet and vehicle management application tracking vehicle assignments, maintenance, and drivers.
**Tech:** CAP, CDS, Node.js

### HR-Model
Human resources data model covering employee records, departments, and organizational hierarchy.
**Tech:** CAP, CDS, Fiori Elements

### Hospital-System
Hospital management system modeling patients, doctors, appointments, and departments.
**Tech:** CAP, CDS, Node.js

### Inventory-Management
Inventory tracking application managing stock levels, warehouses, and item movement.
**Tech:** CAP, CDS, Fiori Elements

### Library-Management
Library system handling books, members, and borrowing/return transactions.
**Tech:** CAP, CDS, Node.js

### Purchase-Order-Model
Purchase order processing system covering vendors, orders, and order line items.
**Tech:** CAP, CDS, Fiori Elements

### University-System
University management application modeling students, courses, and enrollments.
**Tech:** CAP, CDS, Node.js

## 🚀 Getting Started

Each folder is a self-contained CAP project. To run any individual project:

```bash
cd <project-folder>
npm install
cds watch
```

The app will be available at `http://localhost:4004`.

## 📌 About

This repository serves as a portfolio of hands-on SAP CAP and Fiori Elements assignments, demonstrating data modeling, service definition, and enterprise application patterns using SAP's Cloud Application Programming Model.
